# Architecture

Next.js App Router → authenticated, origin-checked REST handlers → services → Mongoose repositories. MongoDB Atlas replica-set transactions are required. Currency is USD in integer cents; configurable basis-point tax applies after discounts, shipping is fixed below a free-shipping threshold. No client prices are trusted.

Collections (volt_ prefix, dedicated volt_commerce database in deployment): users (unique email, role, addresses, wishlist), products (unique slug, variants with globally unique SKU, prices/available stock), categories/brands (unique slug), reviews (unique user/product), orders (unique user/idempotency key, immutable price/address snapshots, payment and fulfillment state), coupons (unique code, atomic use cap), webhook events (unique provider event), audit log, rate buckets (TTL). Orders carry reservation expiry with an indexed state/expiry pair; they are never TTL-deleted. Scheduled expiry releases stock and coupon usage transactionally. COD reserves immediately until fulfillment/cancellation; online reserves for 30 minutes. Paid stock is consumed once and never released by expiry. Stripe Checkout expires on the same deadline. Late payments are refunded through a durable refund state retried by the scheduler. Refund requests persist before provider calls and use provider idempotency keys.

Auth.js credentials + bcrypt, JWT sessions; every protected operation reloads the database user so role revocation takes effect. Mutation origin checks, Zod allowlists, database-backed rate limits, ownership filters, secure headers and Cloudinary signed uploads. Stripe webhook signature verifies raw payload; amount/currency/order/session checks precede fulfillment; event insertion and state transition share a transaction.

Implementation order: schemas/invariants → authentication → catalog and customer UI → transactional checkout/payments → admin → automated checks → deployment configuration. Real Atlas/Stripe/Cloudinary validation requires operator credentials. Local integration tests use an ephemeral MongoDB replica set.
